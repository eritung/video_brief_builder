# Video Brief Builder V1.9

瀏覽器本機版影音需求簡報工具。

## V1.9 重點

- **完全前端處理**：字幕解析、A/B 文本比對、相似度計算、分段、需求編輯、LocalStorage 與 PPTX 產出都在瀏覽器 JavaScript 執行；目前沒有後端。
- **A 文字先校正、B 時間後分段**：進入人工分段頁前，先用字幕 A 校正可確認的 B 文本，再由 B 的時間軸與順序控制簡報。
- **Enter 不再直接拆段**：Enter 是普通同段換行；輸入空白行（連續兩次 Enter）才建立新段。中文輸入法按 Enter 選字不會再觸發分段。
- **可還原／合併**：空白行切錯仍可用段首 Backspace、合併上一段按鈕或「復原上一個分段」。
- **移除匯入卡片 01 / 02 大字**。
- **閱讀性提升**：介面灰字與 PPTX 的 A 時間碼、狀態、需求文字全面放大並加深。
- **PPTX 分頁改為實際高度估算**：依台詞行數、需求行數、連結、圖片估算卡片高度，不再把多張卡硬平均塞滿一頁；過長需求會自動拆成續頁。
- 投影片不輸出 `AUTO VIDEO BRIEF`。

## GitHub Pages

整個資料夾可直接部署到 GitHub Pages；需保留 `vendor/` 內的 `jszip.min.js` 與 `pptxgen.min.js`。


## V1.8 update

- 快捷需求改成分類顯示：畫面、字幕、字卡、素材、聲音、動畫、剪輯、移除、其他。
- 預設需求管理視窗也會依分類分區。
- 分段階段改回 Enter 分段，並保留中文輸入法選字保護。
- 順序調換的自動需求會標示來源 A 時間碼與新版 B 時間碼。


## V1.8 更新
- 分段前先顯示「A 校正過的 B 文字」。
- 新增部分文字移除辨識：簡報顯示完整 A 原句，將被移除文字用紅色刪除線標示。
- 部分移除會自動產生「移除部分文字：…」需求，並與整句移除分開。


## V1.9 更新

- 部分文字移除改為「全文比對防呆」：A 文字若不在目前 B 段落、但仍存在於 B 其他段落，會視為分段差異，不會自動標成移除。
- 分段頁會提示「分段差異」：讓使用者知道內容仍存在於 B 其他段落。
- 匯出簡報時，只有真正從 B 全文消失的文字才會用紅色刪除線與「移除部分文字」需求標示。
- 新增 `split_difference` 狀態，避免把字幕換行／切句差異誤判為新增或刪除。
